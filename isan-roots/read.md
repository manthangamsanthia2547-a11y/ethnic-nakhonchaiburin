# ชาติพันธุ์นครชัยบุรินทร์

Ethnic of Nakhon Chai Bu Rin — เรื่องราววัฒนธรรม อาหาร และชุมชนในนครราชสีมา บุรีรัมย์ สุรินทร์ และชัยภูมิ

## เปิดเว็บไซต์

เปิด `index.html` พร้อมไฟล์และโฟลเดอร์ทั้งหมดในชุดนี้ หรือเสิร์ฟผ่านเว็บเซิร์ฟเวอร์ ตัวอย่างในเครื่องนี้: http://127.0.0.1:4173/#home

## React + TypeScript + Vite + Tailwind CSS

ใช้ Node.js ตามเวอร์ชันใน package.json:

```sh
npm install
npm run dev
npm run check
npm run build
npm run preview
```

Vite สร้างเว็บไซต์ลง `dist/` ส่วน `npm run build:static` สร้าง `home.bundle.js` และ `home.css` สำหรับฉบับเปิด index.html โดยตรง ทั้งสองแบบใช้ React components และข้อมูลชุดเดียวกัน ตัวแปร `HERITAGE_DEPS` เป็นตัวเลือกสำหรับใช้ dependencies ที่ติดตั้งไว้แล้วในเครื่อง ไม่จำเป็นหลัง npm install ตามปกติ

## โครงสร้าง

- `src/components/Header.tsx` — โลโก้เดิมซ้าย เมนู pill และ underline hover; ใช้ตัวควบคุม hash navigation/เมนูเดิมใน app.js
- `HeroSection.tsx` — สไลด์ภาพกิจกรรมล้วน คลิกเปิดหน้ากิจกรรมที่เกี่ยวข้อง
- `IntroductionSection.tsx` — บทนำและดัชนี 4 จังหวัด / 4 ชาติพันธุ์ / อาหาร / วัฒนธรรม
- `EthnicStories.tsx` — ภาพชาติพันธุ์ 4 ช่องเท่ากัน มือถือเรียงแนวตั้ง
- `ProvinceMap.tsx` — เก็บ source ไว้ ไม่แสดงบน Home
- `FoodStories.tsx` — อาหารเรียงแถวตามต้นฉบับ เปิดอาหารเต็มหน้า
- `CommunityStory.tsx` — เก็บ source ไว้ ไม่แสดงบน Home
- `ArchiveSection.tsx` — หน้า Home ใช้ช่องค้นหาแบบย่อ
- `Footer.tsx` — โลโก้ ลิงก์ เส้นทอง ornament และแชร์
- `ui.tsx` — ไอคอน lucide-react และ scroll reveal
- `src/views/HomePage.tsx` — ประกอบหน้าหลัก
- `src/views/EthnicDetailPage.tsx` — บทความชาติพันธุ์พร้อมข้อมูลที่บันทึกไว้
- `src/main.tsx` — เชื่อม React กับเส้นทางเดิม พร้อม unmount เมื่อเปลี่ยนหน้า
- `src/types.ts` — ชนิดข้อมูล
- `src/home.css`, `src/reference.css`, `src/ethnic-detail.css` — รูปแบบ editorial ที่แยก scope
- `src/vite-entry.ts`, `vite.config.mts`, `scripts/build-vite.mjs` — Vite development/build
- `scripts/build.mjs` — สร้างฉบับ static พร้อม Tailwind utilities
- `app.js` — เส้นทาง รายการอาหาร หน้าอาหาร กิจกรรม แบบบันทึกและส่งออก JSON
- `data.js` — ข้อมูล demo และแหล่งอ้างอิงเดิม
- `assets/images/` — ภาพและโลโก้เดิม
- `assets/project-cooking.jpg` — ภาพกิจกรรมที่แนบมา

ไฟล์ component ที่ไม่ระบุ path เต็มในรายการข้างต้นอยู่ใน src/components ทั้งหมด อย่าแก้ home.css หรือ home.bundle.js ที่ root โดยตรง ให้แก้ไฟล์ src แล้ว build ใหม่

## ฉบับคืนโครงหน้า Home

หน้าแรกใช้โครงเดิม: สไลด์ภาพกิจกรรม (ไม่มีข้อความทับภาพ) → บทนำพร้อมภาพซ้อน → ชาติพันธุ์ 4 ช่องเท่ากัน → อาหาร → ค้นหาแบบย่อ → Footer

เอาแผนที่และเรื่องราวเด่นออกจากหน้า Home แล้ว โดยไม่ลบข้อมูลชาติพันธุ์หรืออาหาร ใช้ฟอนต์จากต้นฉบับ: Noto Serif Thai สำหรับหัวข้อ และ Prompt สำหรับเนื้อหา พร้อม Sarabun เป็น fallback ผ่าน Google Fonts URL เดิม ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์ครั้งแรก

ปรับรูปแบบหน้าแรกที่ `src/restored-home.css` ไฟล์นี้โหลดท้ายสุดเพื่อคืน composition และ typography เดิม ส่วน ProvinceMap และ CommunityStory เก็บ source ไว้ แต่ไม่ได้เรียกใช้บนหน้า Home

## รันบน Windows

1. แตก ZIP แล้วเปิดโฟลเดอร์ isan-roots ที่มี package.json
2. คลิกแถบที่อยู่ของโฟลเดอร์ พิมพ์ powershell แล้วกด Enter
3. รัน `npm.cmd install` ครั้งแรก
4. รัน `npm.cmd run dev` แล้วเปิด http://127.0.0.1:5173
5. เปิดหน้าต่างคำสั่งค้างไว้ระหว่างใช้งาน กด Ctrl+C เมื่อต้องการหยุด

หากเพียงต้องการดูฉบับ build พร้อมใช้งาน สามารถเปิด index.html ในโฟลเดอร์หลักได้

## การออกแบบและการใช้งาน

ใช้ภาพ ข้อความ สีครีมสลับพื้นเข้ม และการจัดวางตามต้นฉบับ เนื้อหาหน้า Home กว้างสูงสุด 1180px บทนำอยู่ซ้ายและภาพซ้อนอยู่ขวา ชาติพันธุ์ 4 ช่องเท่ากันบน desktop ส่วนมือถือเรียงแนวตั้ง ภาพอาหารกดเปิดหน้าเต็ม มีสไลด์ เมนูมือถือ และช่องค้นหาที่ยังทำงาน

หน้ารายละเอียดและข้อมูลที่บันทึกไว้ยังคงอยู่ ฟอนต์ของหัวข้อและเนื้อหากลับไปใช้ชุดเดิมทั้งเว็บไซต์

## เส้นทางและการเก็บข้อมูล

- #home
- #ethnic และ #ethnic/khmer, #ethnic/lao, #ethnic/nyahkur, #ethnic/yuan
- #food และ #food/<food-id>
- #activities
- #archive/<group-id>

เก็บ localStorage key เดิม `isan-records-v1` และ schema เดิม ไม่ล้างข้อมูลที่บันทึกไว้ ข้อมูลแยกตาม origin และเบราว์เซอร์ การเปิดผ่าน file://, localhost และโดเมนเผยแพร่อาจเห็นข้อมูลคนละชุด ระบบนี้ยังไม่ใช่ฐานข้อมูลส่วนกลาง

## เนื้อหาและสื่อ

ข้อมูล demo จากเอกสารสาธารณะยังคงแหล่งอ้างอิงเดิม เช่น ศูนย์มานุษยวิทยาสิรินธร กระทรวงวัฒนธรรม Thai PBS มหาวิทยาลัยและรายงานวิจัย ไม่เพิ่มตัวเลขประชากร ชื่อผู้ให้ข้อมูล หรือวันที่สำรวจที่ไม่มีหลักฐาน

รูปอาหารเดิมใช้ประกอบบรรยากาศ ไม่ใช่ภาพยืนยันเมนู จึงมีคำอธิบายกำกับ ชุดไฟล์ยังไม่มีวิดีโอจริง จึงแสดงสถานะว่างและลิงก์ไปเพิ่มบันทึกสื่อ เอกสารเปิดแหล่งอ้างอิงจริงที่เก็บไว้ใน data.js

ระบบเดิมยังไม่มีบัญชีผู้ใช้ การอัปโหลดไฟล์ และซิงก์หลายผู้ใช้ ช่องสื่อเก็บลิงก์ในเครื่อง ดาวน์โหลด JSON เพื่อเก็บสำเนาข้อมูลได้

## ขอบเขตไฟล์

ฉบับปรับปรุงอยู่ใน outputs/isan-roots ใช้ชื่อ โลโก้ ข้อมูล ภาพ และเส้นทางเดิม ไม่ได้เขียนทับโปรเจกต์ต้นฉบับใน Downloads


## เปลี่ยนภาพแบนเนอร์กิจกรรม

### กิจกรรมและข่าวประชาสัมพันธ์บนหน้าแรก

ส่วนนี้อยู่ถัดจาก “เกี่ยวกับโครงการ” และก่อน “เรื่องราวจาก 4 ชาติพันธุ์” ใช้ `src/components/ActivityNewsSection.tsx` และรูปจาก `src/data/activities.ts` แสดงเป็นการ์ดภาพขนาดเท่ากัน 4 คอลัมน์บนคอมพิวเตอร์ 2 คอลัมน์บนแท็บเล็ต และ 1 คอลัมน์บนมือถือ ใช้พื้นหลังส่วนกิจกรรมสีขาว หัวข้อสีเข้ม ข้อความย่อยขนาด 16–18px ชื่อจังหวัดและปุ่มขนาด 16px โดยคงข้อความสีขาวซ้อนบนภาพและปุ่มสีทองตามตัวอย่าง กดแต่ละรายการเพื่อเปิดหน้ารายละเอียดกิจกรรมเดิม ขณะนี้แสดงภาพกิจกรรมที่มีอยู่ ยังไม่มีประกาศข่าวใหม่หรือวันที่เผยแพร่ที่ผู้จัดทำส่งมา

แก้รายการใน `src/data/activities.ts` โดยใช้ bannerImage และ bannerAlt สำหรับภาพหน้าแรก ส่วน image และ alt ใช้ภาพในหน้ารายละเอียดกิจกรรม แต่ละรูปเปิด `#activities/<id>` เมื่อคลิก ภาพแบนเนอร์ 4 ภาพที่ผู้จัดทำส่งมาเก็บใน assets/banners แสดงเต็มสัดส่วนเพื่อไม่ตัดข้อความในภาพ แล้ว build ใหม่เมื่อแก้ไข


### ปุ่มเลื่อนภาพกิจกรรม
ภาพเลื่อนอัตโนมัติทุก 7 วินาที มีลูกศรซ้ายและขวาตรงกึ่งกลางภาพ รองรับการปัดบนมือถือ มีจุดไข่ปลาตรงกลางด้านล่างสำหรับเลือกภาพ ไม่มีปุ่มเล่น/หยุด การกดลูกศรยังคงให้ภาพเลื่อนอัตโนมัติต่อไป ระบบเคารพการตั้งค่าลดการเคลื่อนไหวของอุปกรณ์


### ภาพจาก Google Photos
หน้ารายละเอียดกิจกรรมใช้ภาพที่คัดเลือกจากอัลบั้มที่ผู้จัดทำส่งมา อัลบั้มละ 1 ภาพ รวม 4 ภาพ เก็บไฟล์ไว้ใน assets/activities และลิงก์อัลบั้มใน src/data/activities.ts หน้ารายละเอียดกิจกรรมมีปุ่มดูรูปทั้งหมดใน Google Photos


### Responsive layout
ใช้จอ 1920×1080 เป็นขนาดอ้างอิง กรอบเนื้อหากว้างสูงสุด 1280px อยู่กึ่งกลาง ระยะขอบ 20–80px ตามขนาดจอ ตั้งค่าใน src/restored-home.css ตัวแปร --content-max และ --content-gutter การ์ดรายการชาติพันธุ์และอาหารเป็นคอลัมน์เดียวบนมือถือ

### หน้ารายละเอียดกิจกรรม
ใช้พื้นหลังสีขาว แสดงรูปกิจกรรมก่อนหัวข้อและคำอธิบาย ไม่มีแถบบอกเส้นทางหน้า ตัวอักษรเนื้อหา 18–20px และคำอธิบายภาพ/ปุ่มอย่างน้อย 16px สไตล์จำกัดเฉพาะหน้ารายละเอียดกิจกรรม ไม่กระทบหน้าอื่น ปุ่มอัลบั้มเปิด Google Photos ในแท็บใหม่

### เมนูท้ายเว็บไซต์และหน้าอาหาร
เมนูท้ายเว็บเรียงแนวนอนบนคอมพิวเตอร์ และตัดแถวตามพื้นที่จอบนมือถือ โดยแต่ละชื่ออยู่ด้วยกัน หน้าอาหารรวมเอาแถบ “หน้าหลัก › อาหาร” ออกแล้ว

## การนำทางในหน้าเว็บ

นำแถบเส้นทางแบบ “หน้าหลัก › …” ออกจากทุกหน้าแล้ว ทั้งรายการและรายละเอียดชาติพันธุ์ อาหาร กิจกรรม และคลังข้อมูล ส่วนเมนูหลักและลิงก์สำหรับเปลี่ยนหน้ายังใช้งานได้ตามเดิม

## หน้าข่าวสารและกิจกรรมฉบับใหม่

- `#activities` แสดงการ์ดภาพพร้อมเนื้อหาด้านล่าง โทนเขียวเข้ม–ทอง ค้นหาและเลือกจังหวัดได้
- หน้ารายละเอียดกิจกรรมมีภาพใหญ่ ภาพย่อสำหรับเปลี่ยนภาพ ปุ่มขยายภาพ ลิงก์อัลบั้มจริง และกิจกรรมที่เกี่ยวข้อง
- ไฟล์หลัก: `src/views/ActivitiesPage.tsx`, `src/views/ActivityDetailPage.tsx`, `src/activities.css`, `src/activity-detail.css`
- ข้อความแนะนำอยู่ที่ `src/data/activityStories.ts` ภาพกิจกรรมและลิงก์อัลบั้มเดิมอยู่ที่ `src/data/activities.ts` ไม่มีการเพิ่มวันที่กิจกรรมที่ยังไม่ได้รับการยืนยัน
- รูปและเนื้อหาในหน้า Home รวมถึงโลโก้และเมนูหลักใช้ชุดเดิม


## หน้ารวมอาหารและชาติพันธุ์ตามภาพอ้างอิง

- `src/views/FoodCatalogPage.tsx` — ภาพอาหารขนาดใหญ่ แถบค้นหา จังหวัด ตัวกรองชาติพันธุ์ เรียงชื่อ และสลับตาราง/รายการ
- `src/views/EthnicCatalogPage.tsx` — ภาพปราสาทบนพื้นครีม ค้นหาจากชื่อ/ภาษา/จังหวัด และการ์ดเรื่องราว 4 ชาติพันธุ์
- `src/catalogs.css`, `src/ethnic-catalog.css` — รูปแบบเฉพาะสองหน้ารวม รองรับจอ 1920px, แท็บเล็ต และมือถือ

เปิด `#food` และ `#ethnic` เพื่อดูหน้ารวมใหม่ การ์ดยังเปิดหน้ารายละเอียดเส้นทางเดิม ตัวกรองจะคงอยู่เมื่อกลับจากหน้ารายละเอียดระหว่างเปิดเว็บครั้งเดียวกัน โลโก้และฟอนต์ยังเป็นชุดเดิม และไม่มี breadcrumb
